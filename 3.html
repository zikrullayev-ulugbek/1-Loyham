MEN O'RGANGANLARIM

Men veb-dasturlashni o‘rganish jarayonida HTML, CSS va Figma bilan ishlashni o‘zlashtirdim. HTML yordamida saytning asosiy tuzilishini yarataman, ya’ni sahifadagi matnlar, rasmlar va tugmalarni joylashtiraman.

CSS orqali esa ushbu tuzilmani chiroyli ko‘rinishga keltirib, ranglar, o‘lchamlar va dizayn beraman. Bundan tashqari,

Figma dasturida sayt dizaynlarini oldindan ishlab chiqaman va ularni real kodga aylantiraman. Ushbu bilimlarim orqali zamonaviy va foydalanuvchilar uchun qulay bo‘lgan veb-sahifalar yaratishga harakat qilaman.

HTML

HTML — bu saytning qanday elementlari borligini aytadi (matn, rasm, tugma va boshqalar)

CSS

CSS (Cascading Style Sheets) — bu saytni bezaydigan til.

FIGMA

Figma — bu sayt yoki app dizaynini chizadigan dastur.
